# Project Infinity: Resource Generators

Мод для **NeoForge 1.21.1** (сборка Project Infinity) — 8 уровней генераторов ресурсов, работающих на энергии FE,
и блок хранения энергии без ограничения ёмкости.

| | |
|---|---|
| Minecraft | 1.21.1 |
| NeoForge | 21.1.x (собирается с 21.1.228) |
| Java | 21 |
| Mod ID | `pi_generator` |
| Версия | 0.2 |

Обязательных зависимостей, кроме NeoForge, нет. Mekanism и Applied Energistics 2 нужны для рецептов генераторов,
улучшений и блока хранения энергии (без них эти предметы можно только выдать командой или взять в творческом режиме), Avaritia — по желанию.

Готовые файлы — положить нужный в папку `mods`:

| Файл | Для чего |
|---|---|
| [`release/pi_generator-0.2.jar`](release/pi_generator-0.2.jar) | NeoForge 1.21.1 — текущая версия, всё в этом описании относится к ней |
| [`release/pi_generator-0.1.jar`](release/pi_generator-0.1.jar) | Forge 1.20.1 — старая версия: с Thermal в рецептах, без руд других модов, ядер и блока хранения энергии |

Файл собирается из исходников командой `./gradlew build` (GitHub Actions, workflow `build`, запускается вручную)
и кладётся в `release/` автоматически. Сборка добавляет или обновляет только свой файл и не удаляет версию
для 1.20.1.

### Шансы ресурсов

Перед каждой операцией генератор случайно выбирает, что произвести. У каждого ресурса есть вес: чем ресурс
дороже, тем вес меньше. Шанс ресурса = его вес / сумма весов всех ресурсов, которые генератор сейчас может
произвести. Ресурсы модов, которых нет, в сумму не входят, поэтому точные проценты зависят от набора модов.

| Уровень | Вес: ресурсы |
|---|---|
| 1 | **10**: уголь, сырое железо, сырая медь, сырое олово<br>**8**: редстоун, лазурит, кварц Незера, сырой осмий, сырой свинец, сырой алюминий, сырой цинк, апатит, эссенция инферия<br>**6**: сырое золото, сырое серебро, сырой никель, флюорит, сера, чёрный кварц<br>**5**: киноварь, осколок процветания<br>**3**: рубин, сапфир, перидот<br>**2**: алмаз, изумруд |
| 2 | всё из уровня 1 с теми же весами, а также:<br>**8**: кристалл истинного кварца<br>**6**: сырой уранинит, сырой йеллорий, камень источника<br>**5**: сырое багровое железо, тёмный самоцвет, магический кристалл<br>**4**: сталь, бронза, инвар, сырое лазурное серебро<br>**3**: электрум |
| 3 | **10**: флюикс<br>**8**: насыщенный сплав<br>**5**: очищенный светокамень, сигналум, люмиум, сырой деш<br>**4**: сырая платина, сырой иесний<br>**3**: очищенный обсидиан, сырой иридий |
| 4 | **8**: процессор вычислений, инженерный процессор, логический процессор<br>**6**: укреплённый сплав, сырой уран<br>**4**: дракониевая пыль, сырой острум<br>**3**: эндериум, сырой калорит<br>**2**: сырой оллзэмодиум |
| 5 | **8**: атомный сплав<br>**5**: совершенная схема<br>**3**: сингулярность<br>**2**: сырой вибраниум<br>**1**: звезда Незера, сырой анобтаниум |
| 6 | **6**: полоний, плутоний<br>**2**: слиток кристаллической матрицы |
| 7 | **8**: кучка нейтрония<br>**4**: самородок нейтрония<br>**2**: антиматерия |
| 8 | свои ресурсы — **2**: нейтрониевый слиток, антиматерия; **1**: катализатор бесконечности;<br>плюс все ресурсы уровней 1–7 с теми же весами |

Пример: с одними Mekanism и AE2 генератор 1 уровня выбирает из 14 ресурсов с суммой весов 102, поэтому уголь
(вес 10) выпадает с шансом 10 / 102 ≈ 9,8 %, а алмаз (вес 2) — 2 / 102 ≈ 2,0 %.

- Фильтр меняет шансы: выбор идёт только среди разрешённых ресурсов. С фильтром «только алмаз» генератор делает
  алмаз каждую операцию; с фильтром «только уголь и алмаз» — уголь в 10 случаях из 12, алмаз в 2 из 12.
- Выбор не зависит от предыдущих операций: один и тот же ресурс может выпасть несколько раз подряд.
- Веса можно поменять в `config/pi_generator-common.toml`, список `weights` в разделе `[outputs]`, по одной записи
  `"id предмета=вес"` на предмет (вес — целое число от 0 до 1000, 0 — ресурс не производится совсем):

  ```toml
  [outputs]
  	weights = ["minecraft:diamond=10", "minecraft:coal=0"]
  ```

  Вес действует на этот предмет во всех уровнях генераторов. Записи с ошибкой пропускаются с предупреждением
  в логе. После изменения нужен перезапуск игры / сервера.

### Интерфейс генератора

Открывается ПКМ по блоку (пустой рукой или любым предметом, кроме фильтра и улучшений). В окне:

- шкала энергии слева; при наведении — точные значения заряда и расхода;
- тёмный экран: заряд / ёмкость, расход FE/т с учётом улучшений и состояние: «Работает», «Не хватает энергии»,
  «Буфер заполнен», «Нечего производить» (фильтр отсёк все ресурсы уровня);
- полоса текущей операции; при наведении — тики операции, множители скорости и выхода;
- 4 слота: фильтр ресурсов, улучшение скорости, эффективности, энергосбережения — в каждый кладётся
  только свой предмет, по одной штуке;
- буфер на 27 слотов — из него можно только забирать;
- инвентарь игрока. Shift + клик: фильтр и улучшения уходят в свои слоты, предметы из генератора — в инвентарь.

Рамка экрана, деления уровня (N из 8) и полоса операции окрашены в цвет уровня генератора.

## Блок хранения энергии

Блок `pi_generator:energy_storage` — накопитель энергии FE **без ограничения ёмкости**. Он один, уровней у него нет.

- Ёмкость и скорость передачи не ограничены: блок принимает всё, что ему дают, и отдаёт соседу столько, сколько
  тот берёт за один раз. Запас хранится как число произвольной длины, поэтому он не останавливается ни на
  2 147 483 647 FE (предел интерфейса FE), ни на пределе 64-битных чисел.
- У каждой из шести сторон свой режим, он виден на текстуре стороны:

  | Режим | Вид стороны | Что делает |
  |---|---|---|
  | приём | бирюзовые стрелки к центру | принимает энергию от кабелей и машин; забрать её с этой стороны нельзя |
  | отдача | золотые стрелки от центра | каждый тик сам передаёт энергию в соседний блок; кабели могут забирать её и сами |
  | выключено | тёмная сторона без стрелок | с этой стороны блок ни к чему не подключается |

- При установке сторона, к которой блок приставлен, становится стороной отдачи, остальные пять — приёма.
  Поставили блок на генератор — он его питает.
- Shift + ПКМ пустой рукой по стороне переключает её режим по кругу: приём → отдача → выключено.
- ПКМ открывает окно: запас энергии, приём и отдача за последний тик (FE/т) и шесть кнопок сторон
  (Верх, Низ, Север, Юг, Запад, Восток), которые переключают режим так же, как Shift + ПКМ.
- Сломанный блок выпадает вместе с энергией: запас виден в подсказке предмета и возвращается при установке.
  Режимы сторон при этом сбрасываются. Пустые блоки складываются в стопку, блоки с энергией — нет.
- Другим модам блок показывает запас не больше 2 147 483 647 FE, а со стороны приёма — не больше половины этого
  числа: так он никогда не выглядит заполненным, и кабели не перестают в него передавать. Настоящий запас
  показывают окно блока и подсказка предмета.

Рецепт сложный и требует Mekanism и AE2 — см. «Рецепты».

## Фильтр ресурсов

Предмет `pi_generator:resource_filter` задаёт, что именно производит генератор. У фильтра есть список ресурсов
(до 18) и два режима:

- **всё, кроме выбранного** (по умолчанию) — перечисленные ресурсы не производятся;
- **только выбранное** — производятся только перечисленные ресурсы.

Настройка — в интерфейсе фильтра: возьмите фильтр в основную руку и нажмите ПКМ.

- 18 слотов списка — «призрачные»: клик предметом по слоту добавляет этот ресурс в список, предмет при этом
  остаётся у вас. Shift + клик по предмету в инвентаре делает то же самое.
- Клик по занятому слоту пустым курсором (или Shift + клик по нему) убирает ресурс из списка.
- Кнопка под списком показывает текущий режим (✕ «Всё, кроме выбранного» / ✓ «Только выбранное») и переключает его.
- Один и тот же ресурс добавляется один раз; сам фильтр, пока окно открыто, нельзя переложить или выбросить.

| Действие | Результат |
|---|---|
| ПКМ с фильтром в основной руке | открыть интерфейс фильтра |
| ПКМ фильтром по генератору | установить фильтр (прежний возвращается в руку) |
| Положить фильтр в слот фильтра в интерфейсе генератора | то же самое |
| Shift + ПКМ по генератору пустой рукой | вынуть фильтр (затем, по одному, улучшения) |
| Положить фильтр в сетку крафта | получить чистый фильтр |

Список и режим видны в подсказке предмета. Установленный в генератор фильтр не редактируется — выньте его,
измените и поставьте обратно.
Если под фильтр не подходит ни один ресурс уровня, генератор простаивает и не тратит энергию
(состояние «Нечего производить»).
При разрушении генератора фильтр выпадает.

Рецепт (верстак): 4 железных слитка по углам, 4 бумаги по сторонам, воронка в центре.

## Улучшения

Три вида улучшений, у каждого 4 уровня (предметы `speed_upgrade_N`, `efficiency_upgrade_N`, `energy_upgrade_N`).
В генератор ставится по одному улучшению каждого вида.

| Улучшение | I | II | III | IV | Что делает |
|---|---|---|---|---|---|
| Скорость | x2 | x4 | x8 | x16 | генератор работает во столько раз быстрее; расход FE/т растёт во столько же раз, цена одного предмета не меняется |
| Эффективность | x2 | x3 | x4 | x5 | во столько раз больше предметов за операцию без доплаты энергией |
| Энергосбережение | -25% | -50% | -75% | -90% | снижает расход энергии |

- Установка: положить в свой слот в интерфейсе генератора (или Shift + клик по улучшению в инвентаре) либо
  ПКМ улучшением по генератору — прежнее того же вида возвращается.
- Извлечение: забрать из слота в интерфейсе либо Shift + ПКМ по генератору пустой рукой — по одному:
  сначала фильтр, потом улучшения.
- Если энергии не хватает на полную скорость, генератор работает медленнее, а не останавливается.
- При разрушении генератора улучшения выпадают.

Рецепт (верстак): в центре схема `mekanism:basic_control_circuit` (для I уровня) или улучшение предыдущего уровня,
по сторонам 4 блока вида (скорость — блок редстоуна, эффективность — блок лазурита, энергия — светокамень),
по углам 4 материала уровня (I — железо, II — насыщенный сплав, III — укреплённый сплав, IV — атомный сплав Mekanism).

## Текстуры

Все текстуры нарисованы скриптом `scripts/generate_resources.py`, сторонних картинок в моде нет.

- Генераторы: отдельные текстуры боков, верха и низа, все анимированы (16 кадров) — пульсирующее ядро на боках,
  бегущий по кольцу огонёк излучателя сверху, мигающий индикатор снизу. Цвет уровня: серый, зелёный, бирюзовый,
  синий, жёлтый, оранжевый, красный, переливающийся фиолетовый.
- Фильтр и улучшения: анимированные значки (8 кадров) — светится сердцевина фильтра, блик пробегает по символу
  и делениям уровня улучшения.
- Блок хранения энергии: по текстуре на каждый режим стороны (приём, отдача, выключено); у приёма и отдачи
  анимированы светящаяся ячейка в центре и стрелки (16 кадров).
- Ядра (кристаллическое, нейтронное, ядро Бесконечности): анимированные сферы (8 кадров) в рамке цвета уровня.
- Интерфейсы: свой фон окна генератора для каждого уровня, фон окна фильтра с кнопкой режима.
- Логотип мода для списка модов (`pi_generator_logo.png`).

## Рецепты

Все рецепты используют только Mekanism, Applied Energistics 2 и ванильные предметы. Каждый рецепт включается,
только если установлены моды его ингредиентов.

### Уровни 1–5 — верстак 3×3

В центре — генератор предыдущего уровня (у первого — стальной корпус Mekanism).

| Уровень | Сетка | Ингредиенты |
|---|---|---|
| 1 | `SCS` / `OFO` / `STS` | F — стальной корпус, S — стальной слиток, C — базовая схема, T — энергетическая таблетка, O — слиток осмия (всё Mekanism) |
| 2 | `RCR` / `AGA` / `RTR` | G — генератор T1, R — слиток очищенного светокамня, A — насыщенный сплав, C — улучшенная схема, T — энергетическая таблетка |
| 3 | `OPO` / `AGA` / `OFO` | G — генератор T2, O — слиток очищенного обсидиана, A — укреплённый сплав, P — инженерный процессор AE2, F — блок флюикса AE2 |
| 4 | `NCN` / `AGA` / `KIK` | G — генератор T3, N — незеритовый слиток, C — элитная схема, A — атомный сплав, K — компонент хранения 64k AE2, I — ME-интерфейс |
| 5 | `PCP` / `QGQ` / `PSP` | G — генератор T4, P — гранула полония, C — совершенная схема, Q — кольцо квантового моста AE2, S — сингулярность AE2 |

### Уровни 6–8 — два способа

**С Avaritia** (необязательно): стол 9×9 Re-Avaritia (`avaritia:shaped_table`, `tier: 4`), в центре — генератор
предыдущего уровня. Эти рецепты загружаются, только когда Avaritia установлена.

| Уровень | Ингредиенты на сетку 9×9 |
|---|---|
| 6 | 40 слитков кристаллической матрицы, 32 гранулы плутония, 8 компонентов хранения 256k |
| 7 | 44 нейтрониевых слитка, 28 гранул антиматерии, 8 сингулярностей |
| 8 | 40 слитков бесконечности, 20 блоков нейтрония, 12 гранул антиматерии, 8 катализаторов бесконечности |

**Без Avaritia**: обычный верстак — 8 ядер вокруг генератора предыдущего уровня. Ядра дорогие и собираются
цепочкой: каждое следующее ядро требует предыдущее.

| Предмет | Сетка | Ингредиенты |
|---|---|---|
| Кристаллическое ядро | `PDP` / `NSK` / `PDP` | P — гранула плутония, D — алмазный блок, N — незеритовый блок, S — звезда Незера, K — компонент хранения 256k AE2 |
| Нейтронное ядро | `ACA` / `SXS` / `ACA` | X — кристаллическое ядро, A — гранула антиматерии, C — корпус SPS Mekanism, S — сингулярность AE2 |
| Ядро Бесконечности | `ACA` / `QXQ` / `ACA` | X — нейтронное ядро, A — гранула антиматерии, C — сверхзаряженная катушка Mekanism, Q — камера квантовой связи AE2 |
| Генератор T6 | 8 ядер + центр | 8 кристаллических ядер вокруг генератора T5 |
| Генератор T7 | 8 ядер + центр | 8 нейтронных ядер вокруг генератора T6 |
| Генератор T8 | 8 ядер + центр | 8 ядер Бесконечности вокруг генератора T7 |

Когда включаются рецепты с ядрами, задаёт `coreRecipes` в разделе `[recipes]` файла
`config/pi_generator-common.toml` (после изменения нужен перезапуск):

| Значение | Рецепты с ядрами |
|---|---|
| `ALWAYS` (по умолчанию) | работают всегда, вместе с рецептами Avaritia, если она установлена |
| `WITHOUT_AVARITIA` | только когда Avaritia не установлена |
| `NEVER` | выключены: уровни 6–8 крафтятся только через Avaritia |

### Блок хранения энергии — верстак 3×3

| Сетка | Ингредиенты |
|---|---|
| `AIA` / `DUD` / `AIA` | U — совершенный энергетический куб Mekanism (в центре), I — 2 совершенные индукционные ячейки Mekanism, D — 2 плотные энергетические ячейки AE2, A — 4 гранулы антиматерии |

Совершенная индукционная ячейка — самая дорогая часть: каждая собирается из четырёх ячеек уровнем ниже, то есть
в две такие ячейки уходит 128 базовых.

В Re-Avaritia нейтрониевый слиток и блок называются `avaritia:neutron_ingot` и `avaritia:neutron`.
Рецепты и генераторы понимают оба варианта написания (`neutron_*` и `neutronium_*`).

## Сборка

```
./gradlew build
```

На GitHub: Actions → `build` → Run workflow (на нужной ветке). Сборка запускается только вручную; с включённой
галочкой `publish` готовый jar коммитится в `release/` этой же ветки. Сборка добавляет или обновляет только свой
файл (`pi_generator-0.2.jar`); файл версии для Forge 1.20.1 (`pi_generator-0.1.jar`) остаётся в `release/`.

Нужна Java 21. Результат: `build/libs/pi_generator-0.2.jar`. Зависимостей от Mekanism, AE2, Avaritia и модов с рудами
в `build.gradle` нет.

Текстуры (включая фоны интерфейсов), модели, таблицы добычи, теги и рецепты генерируются скриптом (нужен только Python 3):

```
python3 scripts/generate_resources.py
```
