# Project Infinity: Resource Generators

Forge-мод для сборки **Project Infinity 0.1** — 8 уровней генераторов ресурсов, работающих на Forge Energy.

| | |
|---|---|
| Minecraft | 1.20.1 |
| Forge | 47.2.20+ |
| Java | 17 |
| Mod ID | `pi_generator` |
| Версия | 0.1 |

Готовый файл: [`release/pi_generator-0.1.jar`](release/pi_generator-0.1.jar) — положить в папку `mods`.

| 4 | 65 536 | 10 000 000 | 20 т | эндериум, укреплённый сплав, процессоры AE2, сырой уран |
| 5 | 524 288 | 50 000 000 | 15 т | атомный сплав, совершенная схема, сингулярность AE2, звезда Незера |

| 8 | 1 000 000 000 | 2 147 483 647 | 1 т | по целому стаку за тик: нейтрониевый слиток, катализатор бесконечности, антиматерия + все ресурсы уровней 1–7 |

- Энергия принимается со всех сторон без ограничения скорости (Flux Networks, кабели Mekanism, Thermal, AE2 и т. д.).
- GUI нет: ПКМ по блоку показывает уровень, заряд и расход над хотбаром.
- Внутренний буфер на 27 слотов, предметы можно только забирать. После каждой операции генератор сам
  выталкивает ресурсы в соседние инвентари (ME-интерфейс, сундук, трубы).
- Предметы других модов ищутся по ID во время игры; если мод не установлен, его ресурсы просто пропускаются.

## Фильтр ресурсов

Предмет `pi_generator:resource_filter` задаёт, что именно производит генератор. У фильтра есть список ресурсов
(до 18) и два режима:

- **всё, кроме выбранного** (по умолчанию) — перечисленные ресурсы не производятся;
- **только выбранное** — производятся только перечисленные ресурсы.

Управление (GUI нет, как и у генераторов):

| Действие | Результат |
|---|---|
| ПКМ с фильтром в основной руке и ресурсом во второй | добавить ресурс в список / убрать из списка |
| Shift + ПКМ с фильтром | сменить режим |
| ПКМ фильтром по генератору | установить фильтр (прежний возвращается в руку) |
| Shift + ПКМ по генератору пустой рукой | вынуть фильтр (затем, по одному, улучшения) |
| Положить фильтр в сетку крафта | получить чистый фильтр |

Список и режим видны в подсказке предмета, а состояние фильтра — в строке статуса генератора (ПКМ по блоку).
Если под фильтр не подходит ни один ресурс уровня, генератор простаивает и не тратит энергию.
При разрушении генератора фильтр выпадает.

Рецепт (верстак): 4 железных слитка по углам, 4 бумаги по сторонам, воронка в центре.

## Улучшения

Три вида улучшений, у каждого 4 уровня (предметы `speed_upgrade_N`, `efficiency_upgrade_N`, `energy_upgrade_N`).
В генератор ставится по одному улучшению каждого вида.

| Улучшение | I | II | III | IV | Что делает |
|---|---|---|---|---|---|
| Скорость | x2 | x4 | x8 | x16 | генератор работает во столько раз быстрее; расход FE/т растёт во столько же раз, цена одного предмета не меняется |
| Эффективность | x2 | x3 | x4 | x5 | во столько раз больше предметов за операцию без доплаты энергией |
| Энергосбережение | -25% | -50% | -75% | -90% | снижает расход энергии |

- ПКМ улучшением по генератору — установить (прежнее того же вида возвращается).
- Shift + ПКМ по генератору пустой рукой — вынуть по одному: сначала фильтр, потом улучшения.
- Если энергии не хватает на полную скорость, генератор работает медленнее, а не останавливается.
- При разрушении генератора улучшения выпадают.

Рецепт (верстак): в центре схема `mekanism:basic_control_circuit` (для I уровня) или улучшение предыдущего уровня,
по сторонам 4 блока вида (скорость — блок редстоуна, эффективность — блок лазурита, энергия — светокамень),
по углам 4 материала уровня (I — железо, II — насыщенный сплав, III — укреплённый сплав, IV — атомный сплав Mekanism).

## Рецепты

- T1–T5 — обычный верстак 3×3.
- T6–T8 — стол Re-Avaritia 9×9 (`avaritia:shaped_table`, `tier: 4`).
- Для T6–T8 есть запасные рецепты 3×3 (`generator_tier_N_fallback`). Они включаются сами, если тип рецепта
  `avaritia:shaped_table` не зарегистрирован, либо принудительно: `forceFallbackRecipes = true`
  в `config/pi_generator-common.toml` (нужен перезапуск).

В Re-Avaritia нейтрониевый слиток и блок называются `avaritia:neutron_ingot` и `avaritia:neutron`.
Рецепты и генераторы понимают оба варианта написания (`neutron_*` и `neutronium_*`).

## Сборка

```
./gradlew build
```

Результат: `build/libs/pi_generator-0.1.jar`. Зависимостей от Mekanism, AE2, Thermal и Avaritia в `build.gradle` нет.

Текстуры, модели, таблицы добычи, теги и рецепты генерируются скриптом (нужен только Python 3):

```
python3 scripts/generate_resources.py
```
